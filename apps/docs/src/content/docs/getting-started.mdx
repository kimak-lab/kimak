Three steps. Behavior stays in the kernel. Look stays in the plugin.

## 1. Install

React is the published path:

<PackageTabs packages={["@kimak/ui-react", "@kimak/tailwind"]} />

<Callout title="Vue and Svelte">
  `@kimak/ui-vue` and `@kimak/ui-svelte` ship Button in this repo but are not on npm yet. Consume them from the workspace until they are published.
</Callout>

## 2. Add the look

Requires Tailwind CSS v4. The plugin styles anatomy `data-*` attributes, so any adapter that emits them is styled.

```css
@import "tailwindcss";
@import "@kimak/tailwind/theme.css";
@plugin "@kimak/tailwind";
```

Override **raw** tokens after the import (`--primary`, `--radius`) — not `--color-*`. See [Styling](/docs/styling).

## 3. Render a Button

Switch React, Vue, or Svelte. The choice is stored and reused across the docs.

```tsx
import { Button } from "@kimak/ui-react";

<Button data-size="sm">Save</Button>
```
