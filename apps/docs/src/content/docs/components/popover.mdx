## Usage

```tsx
import { Popover, buttonAttrs } from "@kimak/ui-react";

<Popover>
  <Popover.Trigger {...buttonAttrs({ variant: "outline" })}>Open</Popover.Trigger>
  <Popover.Content>
    <Popover.Title>Dimensions</Popover.Title>
    <Popover.Description>Set the dimensions for the layer.</Popover.Description>
    <Popover.Close>Done</Popover.Close>
  </Popover.Content>
</Popover>
```

`Popover.Content` from `@kimak/ui-react`, `@kimak/ui-vue`, or `@kimak/ui-svelte` renders a portal, the positioner, and the content. Pass `portalled={false}` to render in place. To assemble the parts yourself, use `Popover.Positioner` and `Popover.Content` from the matching headless package (`@kimak/headless-react`, `@kimak/headless-vue`, `@kimak/headless-svelte`).

The trigger has no look of its own. Spread `buttonAttrs()` onto it to make it look like a button: that swaps its `data-scope` / `data-slot` to the button anatomy, so button recipes apply and `[data-scope="popover"][data-slot="trigger"]` no longer matches. ARIA, ids, and `data-state` stay. Without `buttonAttrs()`, style the trigger through the popover selector.

### Sides

`side` is `top` | `right` | `bottom` | `left`. When the preferred side does not fit, the popover flips to the opposite side. `align` (`start` | `center` | `end`) sets the cross axis and follows `dir`.

<PopoverDemo example="sides" />

### Controlled

Pass `open` and `onOpenChange` in React, `v-model:open` in Vue, or `bind:open` in Svelte. Inside the content, `usePopover().setOpen(false)` closes without lifting state. In Vue and Svelte, `usePopover()` returns a getter so reads stay reactive: `const popover = usePopover(); popover().setOpen(false)`.

## Positioning

The positioner is `position: fixed` and moved with `transform`. It re-measures on scroll, resize, and element resize. It exposes CSS variables for content sizing:

| Variable | Value |
| --- | --- |
| `--kimak-available-width` | Room on the cross axis (or main axis for left/right), in px |
| `--kimak-available-height` | Room on the main axis (or cross axis for left/right), in px |
| `--kimak-anchor-width` | Trigger width, in px |
| `--kimak-anchor-height` | Trigger height, in px |

`data-side` and `data-align` on the positioner and content report the placement after collision handling.
