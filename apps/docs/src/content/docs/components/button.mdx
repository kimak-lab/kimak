## Usage

```tsx
import { Button } from "@kimak/ui-react";

<Button variant="outline" size="sm">
  Save
</Button>
```

`variant` and `size` are look-only product props. They write `data-variant` and `data-size` for the plugin. They are not machine props.

The default `<Button>` already renders `Indicator`. Icons are children — any icon library or raw SVG.

```tsx
import { Button } from "@kimak/ui-react";

<Button.Root>
  Save
  <Button.Indicator />
</Button.Root>
```

## Examples

### Variants

`variant` is look-only: `default` | `secondary` | `outline` | `ghost` | `destructive` | `link`.

<ButtonDemo example="variants" />

### Sizes

`size` on the host: `xs` | `sm` | `md` | `lg`. Icon-only sizes are `icon-xs` | `icon-sm` | `icon` | `icon-lg`. Omit it for the `md` default.

<ButtonDemo example="sizes" />

### Icons

Mark a child with `data-icon="inline-start"` or `data-icon="inline-end"` so the recipe reserves spacing. Icon-only buttons need an `aria-label`.

<ButtonDemo example="icons" />

### Loading

<Callout title="Loading stays focusable">
  `loading` stays in the tab order (`aria-disabled` + `aria-busy`, no native `disabled`). `focusableWhenDisabled` does the same for `disabled`. Activation is native Space/Enter, gated when disabled or loading.
</Callout>

<ButtonDemo example="loading" />

### Motion

`motion` is a product-sugar recipe from `@kimak/motion-gsap`, not look and not a machine prop. Default is `press`. Overlay recipes (`ripple`, `shine`, `magnetic`) inherit `currentColor` and belong on boxed buttons, not `variant="link"`. Pass `none` to skip loading GSAP.

<ButtonDemo example="motion" />

### As a link

A link should stay a link. Apply `buttonAttrs()` when you only need the look.

<Callout kind="warning" title="Don't force button semantics onto an anchor">
  Use `buttonAttrs()` on an anchor for look-only. To keep machine behavior, compose with the adapter link API: React `render`, Vue/Svelte `as="a"`. Adapters omit native button attrs on the anchor.
</Callout>

<ButtonDemo example="link" />
