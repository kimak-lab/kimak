Product sugar wraps the headless parts. Install both if you want to assemble anatomy yourself. `@kimak/tailwind` is adapter-agnostic.

## 1. Add the packages

React (peer: React 19. `ref` is a prop — no `forwardRef`):

<PackageTabs packages={["@kimak/ui-react", "@kimak/headless-react", "@kimak/tailwind"]} />

Vue (peer: Vue 3.5):

<PackageTabs packages={["@kimak/ui-vue", "@kimak/headless-vue", "@kimak/tailwind"]} />

Svelte (peer: Svelte 5):

<PackageTabs packages={["@kimak/ui-svelte", "@kimak/headless-svelte", "@kimak/tailwind"]} />

## 2. Point Tailwind at the plugin

Look targets anatomy `data-*` attributes:

```css
@import "tailwindcss";
@import "@kimak/tailwind/theme.css";
@plugin "@kimak/tailwind";
```

`theme.css` is the shadcn token contract: raw values on `:root` / `.dark`, mapped through `@theme inline` to utilities (`bg-primary`, `text-muted-foreground`, `rounded-md`). Override **raw** tokens after the import:

```css
:root {
  --primary: oklch(0.55 0.2 264);
  --radius: 0.5rem;
}
```

See [Styling](/docs/styling) for `variant`, `size`, and `buttonAttrs()`.
