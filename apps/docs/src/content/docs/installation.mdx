v1 publishes `@kimak/headless-react` and `@kimak/ui-react`. `@kimak/tailwind` is adapter-agnostic. Vue and Svelte Button packages exist in-repo and are not on npm yet.

## 1. Add the packages

React product sugar wraps the headless parts. Install both if you want to assemble anatomy yourself.

<PackageTabs packages={["@kimak/ui-react", "@kimak/headless-react", "@kimak/tailwind"]} />

Peer: React 19. `ref` is a prop — no `forwardRef`.

## 2. Optional press motion

`@kimak/ui-react` binds `@kimak/motion-gsap`. Add GSAP only if you want JS press motion. Loading spinner motion stays in the Tailwind keyframes.

<PackageTabs packages={["gsap"]} />

<Callout>
  Do not put `gsap` in core or a headless adapter. This docs app consumes `<Button>` only — it does not re-bind GSAP.
</Callout>

## 3. Vue / Svelte (workspace)

Those names resolve from this monorepo until they are published.

```bash
pnpm add @kimak/ui-vue @kimak/headless-vue
pnpm add @kimak/ui-svelte @kimak/headless-svelte
```

## 4. Point Tailwind at the plugin

Look targets anatomy `data-*` attributes:

```css
@import "tailwindcss";
@import "@kimak/tailwind/theme.css";
@plugin "@kimak/tailwind";
```

`theme.css` is the shadcn token contract: raw values on `:root` / `.dark`, mapped through `@theme inline` to utilities (`bg-primary`, `text-muted-foreground`, `rounded-md`). Override **raw** tokens after the import:

```css
:root {
  --primary: oklch(0.55 0.2 264);
  --radius: 0.5rem;
}
```

See [Styling](/docs/styling) for `variant`, `size`, and `buttonAttrs()`.
